# Woordkaarten

Dutch B1–B2 vocabulary flashcards (onderwijs & studie): spaced-repetition boxes, passive auto-flip mode, swipe to answer on phone, a floating always-on-top card on desktop Chrome/Edge, and word groups that explain the difference between easily confused words.

**Live:** https://ntmytran.github.io/woordkaarten/

On iPhone: open the link in Safari → Share → *Add to Home Screen* for a full-screen app.

Progress is saved on each device (localStorage). The word list is embedded in `index.html`; when it is updated, new words are added and existing progress is kept.

AI features (adding words with details, photo import, regrouping, generated exercises) only work in the claude.ai version.
